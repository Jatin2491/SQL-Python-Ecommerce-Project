# 🛒 SQL + Python E-Commerce Sales Analysis

## 📌 Overview
This project analyzes the Brazilian Olist E-Commerce dataset using MySQL and Python to answer business questions and visualize insights.

## 🚀 Technologies
- MySQL
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
